# Application autofill and submission

## What it does
Fills out application portals in your name using a standing answer set: graduation date, GPA, work authorization, sponsorship, demographics, links. The resume attached always matches the role.

## How it runs
Answers come from a captured set of fixed responses, so forty applications do not produce forty slightly different answers. Tailoring happens by reordering and reframing real experience, never by inventing numbers.

Hard stops are honored: when a posting or assessment bans AI assistance, the agent does not write the answers. It preps instead: role research, a question watchlist, story cards from real material. Captcha walls and portal logins also stop the run; those last two minutes are yours.

## What you get back
Applications that are complete and ready to submit, or already submitted where the portal allows, each logged to the tracker with its confirmation state.
