# Resume ops

## What it does
Keeps the resume matched to every application, and runs JD-versus-resume fit assessments: a score and a gap list per role.

## How it runs
Each job description gets read against the resume. Fit scores come with the reasoning, and weak fits get flagged before an application goes out. Gap analysis names the recurring misses across job descriptions and the single highest-leverage fix, so resume edits go where they buy the most.

Rewrites reorder and reframe real experience with real numbers. They never invent any.

## What you get back
A score and a gap list per role, a clear read on which resume problems cost the most, and the rewrite plan for closing them.
