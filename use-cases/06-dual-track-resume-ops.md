# Dual-track resume ops

## What it does
Runs two parallel resumes, PM and SWE, under a filename convention so the right one attaches every time. Includes JD-versus-resume fit assessments: a score and a gap list per role.

## How it runs
Each job description gets read against the resume for that track. Fit scores come with the reasoning: Workiva 8/10, IBM 7/10, Delta 7/10, and one role dropped outright for eligibility. Gap analysis named the recurring misses across PM JDs (PRDs, roadmap ownership, named Agile tooling, discovery depth, adoption metrics) and the single highest-leverage fix: rewriting a founder project as a product story with real numbers.

## What you get back
A score and a gap list per role, a clear read on which resume problems cost the most, and the rewrite plan for closing them.
