# Daily internship drop watch

## What it does
A daily sweep for new PM and SWE internship postings. PM drops, SWE drops, and a dedicated watch on Google careers run as standing background jobs.

## How it runs
Each pass only counts postings from the last 24 hours, verified currently open at the official application link. Where a posting has a named recruiter, that gets attached. Everything lands in the tracker.

Kills get reported too: closed roles, MBA-only roles, anything ineligible. That keeps dead postings from being re-found and re-read.

## What you get back
One batched report of what is real and new. On a quiet day the report is "thin night, honestly" and nothing else. No padding with stale roles to make the report look full.
