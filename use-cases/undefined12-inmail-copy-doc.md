# InMail copy doc

## What it does
A single Google Doc of copy-paste-ready LinkedIn InMail blocks, ranked in send order: recruiter asks first, then referral asks.

## How it runs
Each block carries a checkbox, the person's LinkedIn URL, a subject, and a body trimmed to two experience bullets so it reads on a phone. Real email addresses are included where verified; the rest stay LinkedIn-DM-only by design, since guessed addresses are never used.

## What you get back
A ranked doc you can work top to bottom, checking off each send, without re-reading a thread to remember who gets what.
